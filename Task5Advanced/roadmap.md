# Стратегический роадмап

Роадмап охватывает период 36 месяцев и включает три этапа:

## Этап 1: Пилот (0–6 месяцев)
- Выбор домена: **Финансы**.
- Внедрение:
  - Kafka как центральной шины событий.
  - Delta Lake в облачном хранилище (AWS S3 / Azure Blob).
  - Первый data product: «Финансовые транзакции клиента».
- Роли:
  - **Data Product Owner** (от бизнеса) — определяет SLA и метрики.
  - **Data Engineer** — строит пайплайн.
  - **BI-аналитик** — создаёт витрину и отчёты.
- Цель: демонстрация time-to-market < 2 недель для нового отчёта.

## Этап 2: Масштабирование (6–18 месяцев)
- Расширение на домены: **Аналитика**, **Операционный**.
- Внедрение:
  - Self-service BI (Superset + GitOps для отчётов).
  - Anti-corruption layer между Camel/DWH и event-шиной.
  - Единый каталог данных (например, Apache Atlas или AWS Glue Data Catalog).
- Автоматизация CI/CD для data pipelines.
- Цель: 70% отчётов строятся без участия ИТ.

## Этап 3: Поддержка и развитие (18–36 месяцев)
- Полный переход на event-driven архитектуру.
- Отказ от синхронных интеграций на критическом пути.
- Внедрение real-time аналитики (Flink / Spark Streaming).
- Доменные команды полностью управляют своими data products.
- Цель: near-real-time аналитика, масштабирование на новые регионы.
