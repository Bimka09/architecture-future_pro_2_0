# Total Cost of Ownership для компании «Будущее 2.0»

Анализ общих затрат владения (TCO) за **3 года** для сценариев:

- **Текущая архитектура (Legacy)** — на базе SQL Server 2008, Power BI, Camel и PowerBuilder.
- **Целевая архитектура (Cloud + Data Mesh + Event-Driven)** — облачная, доменная, самообслуживаемая аналитика.

Цель — обосновать экономическую целесообразность трансформации IT-ландшафта с учётом как прямых, так и косвенных затрат.

## Структура затрат

Анализ охватывает следующие категории:

1. **Инфраструктура** — серверы, хранилища, сети, облако.
2. **Лицензии** — ПО, подписки и т.п.
3. **Сопровождение систем** — администрирование, мониторинг, устранение инцидентов.
4. **Время аналитиков и ИТ-специалистов** — трудозатраты на разработку отчётов, ETL, поддержку.
5. **Разработка и миграция** — инвестиции в новую архитектуру, перенос данных, рефакторинг.
6. **Безопасность и соответствие** — шифрование, аудит, защита ПДн, соответствие законодательству.

## Экономическое обоснование трансформации

### Преимущества целевой архитектуры:

1. **Снижение операционных расходов (OPEX)** — на 30%.
2. **Ускорение time-to-market аналитики** — с недель до дней.
3. **Масштабируемость** — возможность подключения новых бизнес-направлений без рефакторинга DWH.
4. **Гибкость** — домены развиваются независимо.
5. **Повышение качества данных** — за счёт контрактов и автоматического контроля.

### Риски:

- Высокие **начальные инвестиции** (110 млн руб.).
- **Организационные изменения** — необходимость внедрения ролей Data Product Owner, Data Engineer.
- **Культурный сдвиг** — переход от централизованного контроля к доменной автономии.
