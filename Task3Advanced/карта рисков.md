# Карта рисков трансформации

| Риск                                                        | Тип             | Вероятность | Влияние | Описание                                                                                         |
|-------------------------------------------------------------|-----------------|-------------|---------|--------------------------------------------------------------------------------------------------|
| R1. Сложность миграции с SQL Server 2008                    | Архитектурный   | Высокая     | Высокое | Много встроенной бизнес-логики в триггерах, хранимых процедурах. Риск потери данных или логики.  |
| R2. Сопротивление изменению со стороны бизнеса              | Организационный | Средняя     | Высокое | Аналитики привыкли к текущим отчётам; возможен саботаж при переходе на новую систему.            |
| R3. Перегрузка интеграционной шины событий                  | Технологический | Средняя     | Высокое | При масштабировании возможны задержки, сбои в обработке событий.                                 |
| R4. Недостаток экспертизы в event-driven архитектуре        | Организационный | Высокая     | Среднее | Команда не имеет опыта с Kafka, Flink, schema evolution.                                         |
| R5. Потеря согласованности данных между доменами            | Архитектурный   | Средняя     | Высокое | При децентрализации есть риск расхождений в метриках (например, "выручка" считается по-разному). |
| R6. Проблемы с безопасностью медицинских данных в облаке    | Технологический | Средняя     | Высокое | Риск утечки PHI (персональных медицинских данных) при миграции.                                  |
| R7. Зависимость от внешних поставщиков (фарма, электроника) | Организационный | Низкая      | Среднее | Форматы данных могут меняться, нет SLA на поставку.                                              |
